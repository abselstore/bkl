# Bernie Keys Library
This repository contains files supplemental to papers in [_Developments in Business Simulation and Experiential Learning_](https://absel-ojs-ttu.tdl.org/absel/index), also known as the _Bernie Keys Library_. The files may contain relevant data, computations, graphics, and the like that could not be included in the papers, updates to the papers, and discussions of their contents. See [_Submitting Materials_](https://github.com/abselstore/.github/blob/main/submit-materials.md) for instructions on adding files to or changing the contents this repository. When [Requesting changes to repository contents](https://github.com/abselstore/.github/blob/main/request-changes.md) that would require adding to or otherwise changing the table of contents, below, include the change of the table of contents also in the request.
