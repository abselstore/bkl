# Bernie Keys Library
This repository contains files supplemental to papers in [_Developments in Business Simulation and Experiential Learning_](https://absel-ojs-ttu.tdl.org/absel/index), also known as the _Bernie Keys Library_. The files may contain relevant data, computations, graphics, and the like that could not be included in the papers, updates to the papers, and discussions of their contents.

## Table of Contents
1. magnifying_power.xlsx: Excel workbook showing the computation of Figure 1 in [_How to frame game a closed-ended test: Magnifying power, instant feedback, weighted distractors, packing, and dynamic scoreboard_, Vol. 53 (2026), pp. 121-130](https://absel-ojs-ttu.tdl.org/absel/article/view/3466).
